# Linguagem de Programação II — Orientação a Objetos

Repositório destinado ao armazenamento dos códigos desenvolvidos durante as aulas da disciplina **Linguagem de Programação II**, com foco em **Programação Orientada a Objetos**, na **Universidade Estadual da Paraíba — UEPB**.

## Objetivo

Este repositório tem como objetivo organizar os exemplos, práticas e códigos apresentados em sala de aula, servindo como material de apoio para os estudantes acompanharem a evolução dos conteúdos da disciplina.

Os códigos estão separados por turma e organizados de acordo com os assuntos trabalhados em cada aula.

## Organização do Repositório

O repositório está organizado em pastas separadas por **período letivo** e **turno**.
